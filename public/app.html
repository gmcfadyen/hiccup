Keyboard shortcuts

Ctrl K
Open the command palette (⌘ K on a Mac). The one shortcut that still works while you are typing — except in the chat box, where it would interrupt a half-written question.
/
Focus the trace search.
j / k
Move down / up one row in whichever list you last selected in — the sessions tree or the selection list.
?
This list.
esc
Close the palette or this dialog · else clear and leave the search · else close the chat drawer when it is covering the panes on a narrow screen.
tab
Inside a dialog, cycles within it. Closing returns you to wherever you were.

Single-key shortcuts never fire while you are typing in a field — j in the search box types a j.
